\## About This Repository



This repository contains my work for DEV 260: Data Structures \& Algorithms in C#.  

Throughout the course, I learned how core data structures work internally, how to choose the right structure for a problem, and how algorithm efficiency impacts real applications. The repository includes labs, assignments, and a final project demonstrating these concepts in C#.

---



\## Projects



\### Labs



\- \*\*Lab Loops and Conditionals:\*\* Practice using control flow structures such as loops and conditional statements to solve basic programming problems.





\- \*\*Lab Collections:\*\* Introduction to C# collection types and how to work with grouped data effectively.





\- \*\*Lab Stacks:\*\* Implementation and usage of stack data structures following LIFO behavior.



\- \*\*Lab Queues:\*\* Implementation and usage of queue data structures following FIFO behavior.



\- \*\*Lab Hashsets:\*\* Working with HashSet collections to enforce uniqueness and perform fast lookups.



\- \*\*Lab Trees:\*\* Building and traversing tree structures, including binary search trees.





\### Assignments



\- \*\*Assignment DS Foundations:\*\* Reinforcement of data structure fundamentals and problem-solving patterns.



\- \*\*Assignment Linked Lists:\*\* Implementation of linked list structures and node-based traversal.



\- \*\*Assignment Stacks:\*\* Applying stacks to solve structured problems and simulations.



\- \*\*Assignment Queues:\*\* Applying queues for ordered processing and task management scenarios.



\- \*\*Assignment Hashsets:\*\*  Using hash-based structures for uniqueness and performance optimization.



\- \*\*Assignment Trees:\*\* Implementing and navigating tree-based data models.



\- \*\*Assignment Graphs:\*\* Implementing graph structures and algorithms such as BFS and Dijkstra’s algorithm.





\### Final Project



\*\*Media Library Manager\*\*



A console-based media library management application that allows users to add, search, update, and manage media items. 

The project demonstrates the use of dictionaries, lists, and hash-based lookups to efficiently organize and retrieve data.
